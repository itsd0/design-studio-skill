Deterministic linting before delivery

An agent never guesses whether contrast or craft passed. It runs python3 scripts/lint.py in a loop until P0 findings hit zero and every token pair passes WCAG AA/AAA.

  • Zero-dependency Python linter — runs locally in milliseconds with human or --json output.
  • OKLch + Hex contrast math — computes relative luminance across light and dark theme scopes.
  • 14 self-test fixtures — tests/run_tests.py guarantees every shipped seed and demo stays clean.

Install in 10 Seconds

One command for OpenCode, Claude Code, Codex & Cursor.

Install globally with the standard Agent Skills CLI, clone directly into your agent's skills directory, or pipe the zero-dependency shell installer.

1 · Agent Skills CLI 
npx skills add itsd0/design-studio-skill -g
Works across OpenCode, Claude Code, Codex, and Cursor.
2 · Direct cURL Installer 
curl -fsSL https://raw.githubusercontent.com/itsd0/design-studio-skill/main/install.sh | sh
macOS / Linux / WSL — no Node or Git required.
3 · Plain Git Clone 
git clone --depth 1 https://github.com/itsd0/design-studio-skill ~/.config/opencode/skills/design-studio
Drops directly into ~/.config/opencode/skills/.
