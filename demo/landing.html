Inspect the transfer plan before a single byte moves

Ferry computes a cryptographic diff against the destination peer and outputs a dry-run execution plan you can pipe into CI or agent workflows.

  • Pre-flight bandwidth estimation — probes active NICs and picks the lowest-latency path.
  • Zero-copy kernel sendfile — streams directly from NVMe page cache to the socket.
  • Signed completion receipts — emits a verifiable JSON manifest once the target fsyncs.
